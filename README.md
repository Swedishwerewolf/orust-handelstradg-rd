# Orust Handelsträdgård

A clean, responsive static website for a Swedish market garden on the island of Orust, with a built-in Swedish/English language toggle.

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)

## Deployment
This is a static site, so it can be hosted on any static file host (Vercel, GitHub Pages, etc.). See the main project documentation for deployment instructions.
